# md-reader 샘플 문서

이 파일은 **표시 테스트**용입니다. 한글, 코드, 표, 다이어그램이 정상 렌더되는지 확인하세요.

## 1. 기본 서식

- 굵게: **bold**
- 기울임: *italic*
- 취소선: ~~strike~~
- 인라인 코드: `code`

> 인용문도 잘 보이는지.

## 2. 코드 블록

```python
from pathlib import Path

def greet(name: str) -> str:
    return f"안녕하세요, {name}님"

print(greet("홍길동"))
```

## 3. 표

| 항목 | 값 | 비고 |
|------|----|----|
| 한글 | 잘 보임 | UTF-8 |
| 영문 | OK | - |
| 숫자 | 12,345 | 천단위 콤마 |

넓은 표는 가로 스크롤 없이 창 폭 안에서 줄바꿈되어야 합니다.

| 구분 | 담당 | 현재 상태 설명 | 다음 단계 | 위험 요소 | 근거 문서 | 비고 |
|------|------|----------------|-----------|-----------|-----------|------|
| 정적 분석 | 품질팀 | 규칙 위반 경고가 모듈 전체에서 반복적으로 발생하고 있어 원인 분류가 필요하다 | 경고 유형별로 묶어서 담당 모듈에 배정한다 | 일정이 겹치면 검토가 밀릴 수 있다 | https://example.com/very/long/path/to/the/static-analysis-report.html | 주간 회의 안건 |
| 커버리지 | 개발팀 | 분기 커버리지가 목표치에 미달하며 특히 예외 처리 경로가 비어 있다 | 누락 경로 목록을 뽑아 테스트를 보강한다 | 테스트 환경 준비가 늦어질 수 있다 | docs/coverage/summary.md | - |
